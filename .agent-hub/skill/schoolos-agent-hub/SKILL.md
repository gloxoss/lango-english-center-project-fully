# SchoolOS Agent Hub

Several agents from different vendors edit the same SchoolOS working tree at once. The hub is a shared, file-based board that stops them from colliding: claim before editing, log what changed, prove it, and let another agent verify it.

**Repo root:** `C:\Users\OMEN\OneDrive\Documents\projects\lango-english-center-project-fully` (run every hub command from there).

**Hub command:** `node .agent-hub/hub.mjs <command>`. Needs only Node 18+.

## Mandatory workflow

1. **Identify.** Choose a unique id `<tool>-<n>` (for example `codex-1`, `gemini-2`, `claude-3`) and set `AGENT_ID` (bash `export AGENT_ID=codex-1`, PowerShell `$env:AGENT_ID="codex-1"`) or pass `--agent` on every command.
2. **Join and load context.**
   - `node .agent-hub/hub.mjs join --tool <tool> --note "<focus>"`
   - Read `.agent-hub/CONTEXT.md` (app architecture, invariants, databases, ports, commands) and `.agent-hub/PROTOCOL.md` (the full rules).
   - `node .agent-hub/hub.mjs status` and `inbox`.
3. **Pick work.** `node .agent-hub/hub.mjs next`. Verify other agents' finished items first when listed. Each finding's evidence, fix, plan and "Done when" test is in `lango-app/docs/audit/page-audit/findings/<ID>.md`; affected pages and screenshots are in `lango-app/docs/audit/page-audit/pages/`.
4. **Claim before touching any file.** `claim <ITEM> --files <every file to be edited>`. Exit code 3 means another agent holds the item, one of its pages, or a file: pick something else or ask the owner with `say --to <id>`. Lock more files with `files <ITEM> --add <path>` before editing them.
5. **Work inside the claim only.**
   - Heartbeat at least every 20 minutes (`heartbeat --note "..."`).
   - Never edit, revert or reformat files outside the claim.
   - Never run `git stash`, `git checkout -- <file>`, `git restore`, `git reset --hard`, `git clean` or branch switches in the shared tree.
   - Stage only held files, and only when the human asks for a commit.
6. **Finish with proof.** Run the finding's "Done when" check, `npm run check:types`, `npm run check:isolation`, the related tests, and for UI a sweep of the page as the right role (`lango-app/scripts/visual-sweep.mjs`). Then:
   `done <ITEM> --summary "<what changed>" --files <a,b> --verify "<command> -> <result>"`.
   Report failures honestly in `--verify`; never mark done what was not run.
7. **Verify others.** Re-run their check, read `git diff -- <their files>`, then `verify <ITEM> --ok|--fail --note "<what was checked>"`. Self-verification is refused.
8. **Keep the audit folder truthful (automatic).** `lango-app/docs/audit/page-audit/findings/` holds what is left and `findings/done/` what is finished; `STATUS.md` summarizes both. Never move or edit these by hand; the hub does it:
   - `done` sets the finding to REVIEW; `verify --ok` moves it to `findings/done/` and updates pages, links and `STATUS.md`; `verify --fail` returns it as PARTIAL.
   - Partial work: `progress <ID> --partial --note "done: X / left: Y"`.
   - Regression: `claim <ID> --reopen --note "why"` moves it back out of `findings/done/`.
   - After a fix, re-sweep the finding's pages as the right role, then `swept page:/<route> --ok --note "<role + command -> result>"` so the page shows CONFIRMED ON SCREEN.
   - `sync-audit` rebuilds everything if anything looks stale.
9. **Communicate.** `say "<ITEM>: <message>" [--to <id>]`. Questions for the human start with `HUMAN:`.
10. **Leave cleanly.** `release <ITEM> --note "<where it stopped>"` for unfinished work, then `leave`.

## Item ids

| Kind | Example | Locks |
|---|---|---|
| Finding | `S-38` | the finding, all its pages, declared files |
| Page | `page:/dashboard/hr/self-service` | that page, declared files |
| Task | `task:port-3444`, `task:migration-0091`, `task:seed-dates` | whatever it names, declared files |

## Where state lives

- `.agent-hub/BOARD.md`: live view (active agents, claims, free work, done-awaiting-verification, messages). Regenerated by every command; never edit by hand.
- `.agent-hub/CHANGELOG.md`: one entry per finished item plus verification results.
- `.agent-hub/events.jsonl`: append-only source of truth. Never edit by hand.
- `lango-app/docs/audit/page-audit/STATUS.md`: done / in review / partial / open findings plus items needing attention. Rebuilt by the hub; `findings/done/` holds finished findings.

## Safety rules that override everything

- Write test data only to the `schoolos_audit` database; never to production.
- Never build or deploy on the VPS; never kill processes started by another agent; use an own dev-server port and `NEXT_DIST_DIR`, claimed as `task:port-<n>`.
- Every tenant query filters by `tenantId`; the API pipeline order in CONTEXT.md is mandatory.

Run `node .agent-hub/hub.mjs help` for the command list.
