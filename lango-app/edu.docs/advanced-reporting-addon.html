📘 Guide Opérationnel & Business Logic — Rapports & Analytics (SchoolOS)

Module Add-on Officiel Deployed & Verified

Ce document est la référence complète pour comprendre le flux de données, l'utilisation pas-à-pas, le catalogue des 27 rapports types, et les garanties de sécurité (CNDP, Formules CSV, HMAC SHA-256).

🔁 1. Flux de Données & Architecture

Le module Rapports & Analytics est une plateforme décisionnelle gouvernée. Aucune donnée n'est saisie manuellement dans les pages de rapport. Le système lit automatiquement les faits en temps réel depuis les modules opérationnels :

┌─────────────────────────────────────────┐
│          MODULES OPÉRATIONNELS          │
│ (Élèves, Présences, Comptabilité, HR...) │
└────────────────────┬────────────────────┘
                     │ Requêtes SQL/Projections
                     ▼
┌─────────────────────────────────────────┐
│          ADAPTATEURS DE DOMAINE         │
│ (StudentAdapter, AttendanceAdapter...)  │
└────────────────────┬────────────────────┘
                     │ Données Filtrées & Masquées
                     ▼
┌─────────────────────────────────────────┐
│       MODULE RAPPORTS & ANALYTICS       │
│   (Aperçu, Run Engine, Exporateurs)     │
└─────────────────────────────────────────┘

🛠️ 2. Guide de Test Manuel Pas-à-Pas

  1. Parcourir le Centre de Rapports : Ouvrez http://localhost:3000/fr/dashboard/reports. Filtrez par domaine (Élèves, Présences, Frais, Comptabilité, Examens, RH, Stocks).
  2. Favoris en 1-Clic : Cliquez sur l'étoile (⭐) d'une carte de rapport pour l'ajouter aux Mes Favoris. Cliquez sur l'onglet Mes Favoris pour les consulter.
  3. Configurer & Aperçu : Cliquez sur Ouvrir → sur un rapport disponible (ex: /dashboard/reports/student.credentials). Ajustez les paramètres et cliquez sur Aperçu (50 lignes).
  4. Lancer l'Exécution & Exporter : Cliquez sur Lancer le Rapport (Complet) pour traiter le jeu complet de données jusqu'à 50 000 lignes et choisissez CSV, XLSX ou PDF.
  5. Télécharger dans Mes Exécutions : Accédez à /dashboard/reports/runs et téléchargez le fichier généré via un lien sécurisé HMAC SHA-256.

🔒 4. Logic Business & Sécurité Enforced

  • Confidentialité CNDP : Les identifiants élèves masquent les emails (ya***@gmail.com) et excluent les mots de passe. Les résumés de paie RH masquent les salaires individuels pour les groupes de < 3 employés.
  • Équilibre du Bilan Comptable : Garantit l'équation comptable fondamentale : Actifs = Passifs + Capitaux Propres.
  • Protection Formules CSV : Échappe les caractères =, +, -, @ avec ' pour bloquer les vulnérabilités d'exécution de code à distance dans Microsoft Excel.
  • Signature Cryptographique HMAC SHA-256 : Les liens de téléchargement expirent après 24h et utilisent crypto.timingSafeEqual contre les attaques par canal auxiliaire.
