## What We're Building

We're fixing two parts of the school's exam and grading tools. First, "Exam Master" — the tool for organizing exam terms, assigning students to exam halls and seats, scheduling exams without double-booking a room, and entering marks — currently looks real but does nothing: every button is fake, nothing is ever saved. We're making it actually work. Second, the online exam system students actually use today has two real security holes: a student can trick it into giving them a better score than they earned, and it never actually enforces a time limit once an exam starts. We're closing both.

## The Problem

A previous attempt claimed this was "100% executed, verified, and deployed." It was not. Exam Master is a complete demo with hardcoded French sample names — clicking "save" does nothing. The online exam system students use for real today has a scoring bug (it never checks that a submitted answer actually belongs to the question being answered) and never times out a student's attempt. A previous attempt also tried to build a second, parallel online-exam system, but it would have silently collided with the real one in the database — that parallel system is being formally set aside rather than half-built into a confusing second track.

## Who It's For

**Teachers/Exam Administrators** (primary): Set up exam terms, halls, and seat assignments; build the exam schedule without accidentally double-booking a hall; enter marks for paper exams into a real gradebook.

**Students** (primary, for the online exam fix only): Take timed online exams that are graded fairly and cut off exactly when the time limit is reached, not whenever they get around to submitting.

**School Administrators**: Oversee exam terms and rankings across the school.

## What It Does

### Must Have
- Exam Master: create exam terms, exam halls, and generate real seat assignments for a term (no double-booked seats).
- Exam Master: schedule an exam into a hall/time slot, with the system refusing to double-book a hall that's already in use at that time.
- Exam Master: enter marks for a class into a real gradebook, and see a real ranked list of results.
- Online exams: a submitted answer is only scored correct if it actually belongs to the question the student was asked — closing the score-forgery hole.
- Online exams: an attempt is cut off at its real time limit, not left open indefinitely.
- Homework: a student only sees homework actually assigned to their class, not every homework in the whole school.
- A rebuilt set of automated checks proving these fixes are real, not just claimed.

### Explicitly Not Building (see "What It Does NOT Do")
- The second, parallel online-exam system a previous attempt started (question-bank authoring, server-timed delivery layer) — being set aside, not built out, because it would collide with the real system students already use.

## How It Should Feel

Exam Master's pages already look right — the fix is entirely about making the buttons and forms actually save and load real data, not changing how anything looks. Nothing changes about the online exam student experience except that it now genuinely enforces the time limit it already claims to have.

## What It Connects To

No new outside connections. Exam Master reuses the same grading ledger already used by homework. The online exam fix touches only its own existing database tables.

## What It Does NOT Do

- Does not build a second online-exam delivery system — the previously-started parallel one is formally shelved, not completed, because it would silently collide with the live system's database table.
- Does not add the extra schema (question versioning, exam blueprints, accommodations, a manual-grading queue) a previous plan wanted but never built — those aren't needed to fix what's actually broken, and adding them now would be new speculative work, not a fix.
- Does not change how homework grading or the shared ledger works — those are already real and correct.

## How We'll Know It Works

- A real exam term, hall, and seat assignment can be created and actually persist — checked against the real database, not just a success message.
- Trying to double-book an exam hall at an overlapping time is genuinely rejected.
- A real mark entered through the marksheet grid shows up in the shared gradebook and the ranking list.
- A submitted online-exam answer using a "borrowed" correct-option ID from a different question is rejected, verified by actually trying it.
- An online-exam attempt past its time limit is rejected, verified by actually trying it.
- A student only sees homework genuinely assigned to them, verified by comparing two different students' homework lists.
- Every check above holds for a second, separate school (tenant) too, with no data crossing between schools.

## Business Model

Not applicable — this is a core part of the existing product, not a separately licensed add-on (unlike the reporting tool fixed earlier in this session).

## Risks & Concerns

1. **Formally shelving a chunk of previously-written code (the parallel online-exam system)** is a judgment call, not something the code itself demanded — but activating it would require either renaming its colliding table or migrating live student exam data onto a new shape, both bigger and riskier than the actual problem (a scoring bug and a missing timeout) requires solving.
2. **The online-exam fix touches a live, real-money-adjacent-in-trust system** (student exam scores) — extra care and live re-testing matter here specifically.
3. **Same defense as always this session**: nothing here is trusted as "done" without independently trying it against the real running app and real database.
