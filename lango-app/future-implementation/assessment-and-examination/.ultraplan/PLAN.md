# Assessment & Examination — M13 De-Mock & Close-Out — Technical Plan

> Generated by UltraPlan | 2026-08-14

## Architecture Overview

The assessment module's backend is already complete and live: shared outcome ledger (`OutcomeService`), homework (`HomeworkService`), Exam Master (`ExamMasterService`), and the legacy MCQ online-exam flow (migration `0025`). The rich "Online Examinations addon" (question bank, blueprints, server-timed runner, live monitor, accommodations, QTI) was formally **retired 2026-08-13** — `OnlineExamService` deleted, dead `0060` tables dropped via migration `0117` (see `STATE.md`).

What remains is a **UI honesty pass**: three dashboard pages under `/dashboard/academics/assessment/*` are in very different states. Exam Master is fully wired; Homework is a real/API hybrid polluted with hardcoded demo seed data and a fake `studentId`; Online Exams is a 100% hardcoded mock that advertises exactly the features that were retired ("248 questions", "live monitor", "92% auto-correction"). This plan makes those two pages honest, verifies Exam Master, and closes out the stale docs + tracker.

No new backend, no new tables, no new migrations. This is de-mocking plus documentation.

## Tech Stack

Unchanged — Next.js App Router, Drizzle, PostgreSQL, existing `fetch()`/loading/error-state patterns already used elsewhere in the codebase.
